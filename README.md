# Mediroza General Hospital — Penetration Testing Lab

Black-box penetration testing lab on `https://medirozahospital.com` (5-day controlled educational engagement)

## Milestones
* **M1 — Initial Access:** Found open directory listing at `/patient/` on LiteSpeed Web Server, exposing `reports/` and internal files (`error_log`, `download.php`, `portal.php`) to retrieve the 3 patient PDF lab reports.
* 
* **M2 — Encryption & File Recovery:** Cracked/analyzed encryption on the 3 retrieved PDF files to access their contents.
* 
* **M3 — Sensitive Data Exposure:** Inspected retrieved data and file properties to find hospital employee salaries and shareholder details.
* 
* **M4 — Pentest Report:** Documented executive summary, scope & methodology, findings with proof, risk ratings, and remediation steps.

> Conducted in a controlled environment for educational purposes only with authorization.
